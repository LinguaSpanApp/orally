# **App Name**: Oraly

## Core Features:

- Dataset Import & Parsing: Allow users to upload CSV files or paste tab-separated text data (ID and Sentence), which the app will parse and present as an editable list of sentences.
- Sentence Navigation Interface: Display one sentence at a time, allowing users to move between sentences using 'Next' and 'Previous' buttons.
- Real-time Audio Recording: Implement a prominent record button that clearly indicates when recording is active, capturing the user's voice for the displayed sentence.
- Instant Audio Playback: Provide controls to immediately play back the most recently recorded audio for the current sentence.
- Rerecord Functionality: Allow users to easily rerecord audio for any sentence, replacing previous attempts.
- AI-Powered TTS Preview Tool: A tool that generates an AI-voiced preview of the current sentence, assisting users with pacing and pronunciation prior to their own recording.
- Recorded Audio Export: Enable users to export all recorded audio files, linked to their corresponding text IDs, for external use.

## Style Guidelines:

- Primary color: A clear, inviting blue (#337ACC) to convey communication and technological precision.
- Background color: A subtle, very light desaturated blue (#ECF3F9) to provide a clean and focused workspace.
- Accent color: A vibrant turquoise (#33CCE0) for highlighting interactive elements and call-to-actions, ensuring good contrast and attention.
- Body and headline font: 'Inter' (sans-serif) for its modern, objective, and highly readable qualities, suitable for displaying text that users need to read clearly.
- Utilize clear and universally recognized icons for audio controls (e.g., record, play, stop) and navigation (e.g., next, previous).
- Employ a clean and uncluttered layout, placing the sentence to be read prominently at the center of the screen, with recording and navigation controls easily accessible.
- Incorporate subtle animations for button states, recording status indicators, and transitions between sentences to provide smooth user feedback.
